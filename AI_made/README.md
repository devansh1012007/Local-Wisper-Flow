# Local-Wisper-Flow

A headless dictation engine foundation with a local web dashboard.

## Quick start

- Run the engine:
  - python -m vision_sst --port 50051
- Run the UI:
  - python -m vision_sst.ui_server
- Or from Windows:
  - start-ui.bat
- Or with Docker Compose:
  - docker compose up --build
