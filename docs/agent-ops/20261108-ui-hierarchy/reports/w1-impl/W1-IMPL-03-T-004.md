## 4. Approach + alternatives

Line-based lexical scanner over the 9 scoped files (MainWindow.cpp, 5 pages .cpp,
widgets Buttons/Display/Overlays.cpp) with LWF_SOURCE_DIR-first ReadSource (pattern
tests/test_transforms_page.cpp:30-44). Per-line anchors: PushFont(nullptr, N),
Dummy(ImVec2(0.0f, N) height, Dummy(ImVec2(N,...)) width, SameLine(0.0f, N),
SetNextItemWidth(N); universal factors {0,0.5,1,2} + -1.0f fill sentinel exempt;
token-carrying lines (metrics::/studio_metrics::) and identifier / named-constant
arguments exempt. Rejected: <regex> scanner (heavier, worse failure text); touching
dictionary/insights/transforms tests (read-only; their requirements live in the
overlay ban TEST_CASE); exact-count allowlist (ceilings instead, so improving a gap
site keeps the test green). Generic ImVec2 outside Dummy (PushStyleVar padding,
Button extents) is NOT one of the five P-005 APIs and is deliberately unscanned
(Deviation 3).
