## 3. Root cause
Central tokens (`metrics::space_*`, `control_min_height`, `radius_*`, `font_*`) were
defined, but hand-drawn controls (ToggleSwitch, rail, tabs, chips, bottom status,
Saved overlay) kept design-px literals inline [VERIFIED Source Palette
src/ui/theme/ThemePalette.h:85-107; MainWindow.cpp:83-98,469,521-531,806-807,1563-1568].

## 4. Approach + alternatives
Approach: role-aware same-value substitution. Dummy/SameLine/spacing literals map
only where the token's role matches (spacing→`space_*`, control height→
`control_min_height`); counts verified against `ThemePalette.h:85-97`. A
value-only substitution was rejected where roles mismatch (e.g. knob 24 →
`space_l` "between groups"; 8px rounding → `space_s`): that would silence the
scan while lying about intent (W0-INV-02 §1.4 — same value, different roles).
Adding `ThemePalette` tokens was rejected (frozen hotspot, outside WRITE-SET;
brief/forbidden). Leftover literals are allowlisted with a per-value reason (§5).
