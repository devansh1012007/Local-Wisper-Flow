## Phased Changes Executed
### Phase 1 — NotesStore (src/core/NotesStore.h/.cpp)
- Public API: `Note{id,title,body,created_at,modified_at,pinned}`; `Create(title,body) → optional<Note>`; `Update(id,title,body) → bool`; `Delete(id) → optional<Note>` (deleted copy out for the 5 s undo toast); `Restore(note) → bool`; `Pin/Unpin(id) → bool`; `List/Search → vector<Note>`; `Get(id) → optional<Note>`; `Size`; `Reload() → bool` (false ⟺ corrupt signature recovered). `List` sort total order: pinned desc → `modified_at` desc → `created_at` desc → `id` asc (ids unique ⇒ deterministic across equal-second timestamps). `Search`: ASCII-case-insensitive substring over title+body (bytes ≥0x80 pass through, sibling-consistent), blank query ⇒ `List`, results in `List` order. `Pin/Unpin` persist index only and do not bump `modified_at` (`INVARIANT: pinning is a view operation, never a content modification — List order within the pinned group must not churn on pin`). Idempotent `Pin`/`Unpin` (already-state ⇒ true, no write — retry-safe; the rollback invariant below guarantees memory==disk so skipping the write heals nothing).
- Titles (`ResolveTitle`): trimmed explicit title wins; empty/whitespace explicit ⇒ first non-empty trimmed body line (handles `\n`/`\r\n`); none ⇒ `Untitled`. Applied uniformly at Create/Update/Restore/load, so hand-edited empty index titles self-heal and persist via dirty bit.
- IDs (`IsValidId`: non-empty, ≤128 chars, not `.`/`..`, no `/\` or controls — blocks path traversal in corrupt/hand-made index; spaces allowed so adopted stems round-trip). `GenerateIdLocked`: `note-<seconds>-<n>` first candidate absent from memory AND from disk (mirrors SnippetStore `GenerateIdLocked` "snippet-<now>-<n>"). `Restore` rejects invalid ids and existing ids (false); timestamps default when zeroed (created←modified←now, then modified⇒created). Adopted orphans: id = filename stem, title via `ResolveTitle`, `created_at = modified_at = NowSeconds`, `pinned = false` (uses adoption time, not filesystem mtime — avoids clock-domain conversion; file content (`derive title`) is preserved, wall-clock fidelity is not needed for correctness).
- Persistence (`WriteBodyLocked`/`WriteIndexLocked`): `create_directories` (first Save creates `notes/` per STUDIO_PLAN), `<path>.tmp` trunc-write + flush + rename, rename-failures remove `.tmp` and return false (AtomicFile.h:26-33 shape, inline per wave convention — the brief gates on a `check_no_network.sh` allowlist NEED, and 02B/02C/02D all keep the inline pattern; switching to `lwf::WriteAtomic` later is a one-call-per-write swap once the gate allowlist consolidates, noted here not in code). Index persisted in `List` order, JSON pretty `dump(4)` + `\n` (StatsStore/Dictionary/Snippet precedent). `Delete`: md `remove` first, then index write — deleting commits at the body layer before the index layer (crash between ⇒ dangling index entry ⇒ Load drops ⇒ delete sticks; the reverse order would resurrect via orphan adoption).
- Load (`LoadLocked`): missing `notes/` ⇒ empty, true, **no creation** (creation only on a mutating Save). Index: non-object/bad-id/duplicate entries skipped; malformed id dropped (hostile-path test: `../evil` never read); unreadable `.md` ⇒ entry dropped + dirty; title normalized. Corrupt (parse failure / non-array / empty file) ⇒ stream closed, renamed to `index.json.bad` (evidence preserved), empty base, then orphan sweep, then persist; returns false. Orphan sweep: regular files `*.md` only (`.tmp`/`.txt`/`.bad` ignored), stem validity, dedup vs index, body read (unreadable skipped). If dropped/adopted/normalized ⇒ `WriteIndexLocked` (best-effort, in-memory reconciled regardless; next mutation heals on failure). `Reload` restart-safe: a second load is idempotent (verified — reload tests reconstruct and re-`Reload` without duplicates).
- `DECISION — persistence-failure invariant (full rollback)`: every mutating op applies, persists md-then-index, and on persist failure undoes the in-memory change (Create/Restore erase the entry; Update/Delete restore the backup, Delete/Update also re-write the body file from the backup so both planes agree again; Pin/Unpin flip back) and returns false/nullopt. `INVARIANT: false ⟹ observable state unchanged (List/Get/Size pre-call == post-call, barring the single-`rename`-window disk residual below)`. Retries are therefore always safe. Crash residual (by design — reconciliation, not 2-file txn, plan §D): process death between the two renames leaves md-only (adopted on next Load) or index-only (dropped on next Load). Double-disk-failure corner: Update/Delete rollback body rewrite itself failing leaves the NEW body on disk under the OLD stored metadata; nothing is lost (the newer body is preserved and surfaces on next Load), the rest is stale until the next successful write heals it.
- Privacy: no `Log.h`, no network headers, no API keys; `.md` bodies never leave the process; index `title` rows are file-local only.
