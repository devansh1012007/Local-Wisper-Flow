## Phased Changes Executed

### Phase A — AtomicFile (T-002)

New: `src/core/AtomicFile.{h,cpp}`, `tests/test_atomicfile.cpp`.
`WriteAtomic`: open `path+".tmp"` truncated (stale tmp overwritten), write exact content, flush, check `good()`, close; `rename(tmp, path)`. Failure at open/write/rename → remove tmp, return false, previous target untouched. INVARIANT: the target file only ever changes via rename; a crash mid-write leaves a `.tmp` that the next write truncates. INVENTORY NOTE: initial AtomicFile.h draft contained invented `§1.` prose lines (not a codebase convention, would not compile) — caught on self-review, rewritten to bare-decl style.

### Phase B — TextDiff (T-003)

New: `src/core/TextDiff.{h,cpp}`, `tests/test_textdiff.cpp`.
UTF-8 decoder with graceful fallback (invalid sequences become single-byte tokens); `IsSpaceCodePoint` covers the Unicode `White_Space` set (0x09-0x0D, 0x20, 0x85, 0xA0, 0x1680, 0x2000-0x200A, 0x2028/29/2F, 0x205F, 0x3000). Full LCS DP + backtrack. Counts: `replaced = min(raw_ins, raw_del)`, remainder to pure ins/del. INVARIANT: Equal count == LCS length; forward token order preserves both texts.

### Phase C — InsightsModel (T-004)

New: `src/core/InsightsModel.{h,cpp}`, `tests/test_insights.cpp`.
`Wpm`: `speaking_ms < 60000` → `nullopt`, else `max(words,0) * 60000.0 / ms`. `FixesMadeByFlow`: sum of positive `fixes`. `CategoryShares`: aggregate positive words per category; empty when total is 0; floors then distribute remainder +1s in sorted order (share desc, name asc) so the sum is exactly 100. `TotalAppsUsed`: distinct non-empty `app`. Streaks: sum words per day, parse `YYYY-MM-DD` strictly (reject malformed), convert via days-from-civil; current = run ending at today only if today is active. `CalendarLevel`: integer quartiles (`day*4/max`, clamped 1..4), 0 when day or max ≤ 0, day ≥ max → 4. `DayKey`: `snprintf("%04d-%02d-%02d")`.
