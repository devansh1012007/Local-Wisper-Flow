No comments added.
Phase 3 — Overlays.{h,cpp}: Toast `##toast_action` + cursor save/restore; Modal/Sheet `visible_` + guarded `End` + title-null guard. INVARIANT: Push/Pop balance unchanged; Esc/armed-once semantics unchanged.
