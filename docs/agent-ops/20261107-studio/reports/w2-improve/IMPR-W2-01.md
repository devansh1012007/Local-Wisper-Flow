## 2. Root cause & context summary
Root causes fixed, not symptoms: the transform suite was dead because the test file was committed without its CMake line (integrator dropped E2's NEED); the prod engine was dead because `main.cpp` never called `Start()` (events accumulated forever); the transform LLM wedge existed because `HandleTransform` called `Process` inline with no timeout and `ILlmProvider::RequestCancel()` was never forwarded; diff OOM existed because unbounded clipboard input flowed into `TextDiff`'s O(n·m) table before `RestoreClipboard`; settings hot-apply drift existed because the engine held a ctor copy of `EngineSettings` while main mutated a different copy (formal data race once timers become live, since `Start()` now runs). Each fix below removes the mechanism. Pre-existing behaviors preserved: pipeline order, FSM, dictation exclusion paths (cancel/empty/failed/command/pastelast), opt-in gating order (Enabled before slot read), 3x+200 + preamble validation semantics (except extended boundaries), 40 s retention, clipboard restore on every existing branch.
