Local Wisper Flow — Full UI redesign reference

Phase 1 (Full Unify + Ivory Light primary). This file is the visual source of truth for Phase 2 token work. Single Palette struct, Ivory Light primary, dark as named variant.

Fonts shown are system stand-ins. EB Garamond (serif display) and Inter (sans body) remain a proposal pending bundling — no font files added in this phase; the app keeps the scaled default font. Type sizes below are design px at 1.0 scale and map to metrics::font_* tokens.

Contrast is computed with the WCAG relative-luminance formula: L = 0.2126R + 0.7152G + 0.0722B over linearized sRGB channels (c/12.92 if c<=0.03928 else ((c+0.055)/1.055)^2.4), ratio = (Lhi+0.05)/(Llo+0.05). Policy: all text pairs >=4.5:1, meaningful non-text >=3:1, only the two declared hairlines (border/bg, border/surface) exempt below 3:1.

Contents: Single Palette, Contrast, Type, spacing, radii, controls, Deprecation + heat ramp, Full shell, Home, Speech / Settings, Studio pages, Mini states, Motion, state, accessibility, Phase 2 contract

What changed in Phase 1 (summary). Single accent per view: brass only. Light accent unified from navy #1F3A5F to brass #7A5C25 (accent/brass/focus all brass on light); navy eliminated. Dark Hunter/Brass values retained as the named variant so the struct shape is unchanged. Studio teal deprecated and absorbed into the same Palette. Radius reconciled to one radius_card = 10px. Rail canonicalized to 220px (token 208 retired). Mini fade-in standardized to 150 ms to meet the 150–240 ms functional-motion band.

10. Motion, state-pairing, accessibility

10A. Motion rules

MotionDurationRule
Functional (hover, press, open, knob, Saved fade)150–240 msSingle band for all feedback; mini fade-in standardized to 150 ms (was 120 ms).
Saved dwell1.5 sWord shows, then fades in the functional band.
Ambient (listening ring 2.4 s, bars 1.2 s, thinking 0.9 s)own periodsFreezes at a static pose when reduce-motion is on; never the only feedback (word + dot remain).
Done check → Ready0.6 sBrief check then Ready word.
Attention auto-clear6 sMessage clears without hiding word history.

Reduce-motion: any prefers-reduced-motion path (OS setting or in-app) stops all ambient loops and shortens functional fades to instant. Mockup honors it via CSS media query.

10B. State-pairing (never color alone)

  • Word + shape + color for every status: Ready (✓/dot + word + ok), Listening (ring/bars + word + accent), Transcribing (dots + word + accent), Needs attention (err_fill dot + word + message + err).
  • Toggles show On/Off words; active nav shows bar + bold + accent; heat shows numeric label + legend + ramp.
  • One accent per view (brass). Status colors (ok/warn/err) are not accents; they never replace the accent for primary actions.

10C. Keyboard, DPI, window sizes

  • Keyboard: Tab order rail → page chrome → cards → controls; Enter/Space activate; Esc closes Mini message; invisible buttons (rail items, icon buttons) pass EnableNav; focus ring 2 px accent visible on all stops (overshot 32 px hit boxes).
  • DPI: 100/150/200% verified at 960×640 default and 760×520 minimum. Scale applied once via style.FontScaleMain; scoped fonts use PushFont(design px) so DPI multiplies once.
  • Sizes: Full default 960×640, min 760×520 (rail 220 + content min 540 keeps rows unclipped). Mini dot 22 px, message 250×48, margin 16 px.
  • Structure preserved: rail + pages, live-apply + Saved dwell, hide-on-close with tray Quit, Mini dot→pill states (§9). Third context (Scratchpad) keeps its own ImGui context and drag.

11. Phase 2 contract (what to implement)

  • Single Palette per theme with the exact §1 hex (0xRRGGBB). Keep field names; change only kLightPalette::accent/focus to brass #7A5C25. Dark values unchanged as the named variant.
  • Delete StudioPalette; pages/widgets resolve through Palette. HeatColor(level) maps to §4B.
  • Set metrics::rail_width = 220 (retire 208), radius_card = 10 single value, font_body_px = 14, fade_in = 0.15.
  • Tests keep the ≥4.5 / ≥3.0 / hairline-exempt policy; update pins to §1/§2 values. Keep EK: every text pair incl. accent/ok/warn/err/brass/muted/on_accent ≥4.5; only border/bg + border/surface asserted <3.0.
  • Fonts: keep scaled default font; EB Garamond/Inter stay proposal pending bundling (no new files).
